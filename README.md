# 🌦️ Weather Dashboard App

A modern, responsive Weather Dashboard built with Next.js, Tailwind CSS, and Zustand. This application allows users to check real-time weather conditions for different cities with a sleek user interface and smooth theme synchronization.

Live Demo: https://nextjs-weather-app-one-iota.vercel.app/
---

## 🚀 Features

- **Real-Time Weather Data:** Fetch and display accurate weather information for various locations.
- **City Search:** Easily search for any city to view its current weather status.
- **Responsive Design:** Fully optimized for all screen sizes, from mobile devices (320px+) to large desktop monitors.
- **State Management:** Powered by Zustand for lightweight and efficient global state management.
- **Dark/Light Theme:** Dynamic theme adaptation based on weather data or user preference.

---

## 🧰 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React Framework)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Language:** JavaScript / TypeScript
